# AI Autoplayer

Adds an **AI** button under the copy button on any level's page.

Press it and an AI plays the level in practice mode, dying and retrying until it beats it. The winning run is then saved to your PC as a `.gdr.json` macro, and a **Replay** button shows up on that level's page so you can watch it.

- Classic (non-platformer), 1-player levels only
- Runs in practice mode, so the AI's run never counts as your completion
- Tweak speed and search precision in the mod settings
